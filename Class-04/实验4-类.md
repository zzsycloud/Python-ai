## 第 3 题：商品类 Commodity

要求：

1. 定义`Commodity`类，实例属性：商品名称`name`，成本价`_cost`，售价`_price`。

2. 使用@property装饰器封装售价：

   - 获取售价直接返回`_price`；
   - 修改售价时，要求售价**不能低于成本价**，低于成本则提示，不修改价格。
   
3. 定义类方法`get_discount_rate(origin_price, sell_price)`：根据原价与折后价，返回折扣率。

4. 重写`__repr__`魔术方法，输出商品的名称、成本、售价信息，方便打印对象。

5. 创建 2 个商品实例，测试修改售价（包含一次非法修改），调用类方法计算折扣，直接 print 对象查看效果。

**示例运行效果：**

```
售价不能低于成本价！
Commodity(名称=笔记本,成本=30,售价=50)
Commodity(名称=鼠标,成本=20,售价=32)
折扣率：0.8
```

## 第 5 题：图书馆与图书借阅系统

要求：

1. 定义`Book`类：私有属性`__is_borrowed`（标记是否借出），属性书名、ISBN；方法`borrow()`、`return_book()`用于修改借阅状态。

2. 定义Library类：实例属性book_list，保存馆藏图书列表；

   - `add_book(book)`：添加图书到馆藏，不能重复添加相同 ISBN 图书；
   - `borrow_book(isbn)`：根据 ISBN 借书；图书不存在 / 已借出则提示失败；
   - `return_book(isbn)`：还书；图书不存在或者未借出提示失败；
   - `show_all_books()`：列出全部图书及借阅状态。
   
3. 测试：创建 3 本图书，加入图书馆；执行借书、重复借书、还书、重复还书等场景。

**示例运行效果：**

```

ISBN:978001,书名:Python编程,状态:可借阅
ISBN:978002,书名:面向对象程序设计,状态:可借阅
ISBN:978003,书名:数据结构,状态:可借阅
借书成功：978001
借书失败：该书已被借出
还书成功：978001
还书失败：该书未借出
```

## 第 6 题：数据库连接池

要求：

1. 实现数据库连接`DBConnection`类，要求**单例模式**：无论创建多少次实例，内存中始终只有同一个对象。
2. 实现上下文管理器\_\__enter\_\_ 和 \_\_exit\_\_：
   - `with`语句进入时：输出 “建立数据库连接”，标记连接为已打开；
   - 代码块结束时：输出 “关闭数据库连接”，标记连接关闭；代码块内发生异常，在`__exit__`捕获并打印异常信息，依然关闭连接。
3. 增加方法`execute_sql(sql)`：只有连接打开状态才允许执行 SQL；连接关闭时，提示无法执行。
4. 测试：
   - 验证单例：两个对象`conn1`、`conn2`，判断`conn1 is conn2`结果为 True；
   - 使用`with`语法执行 sql；
   - 在 with 内部制造一段错误代码，测试异常自动捕获、连接自动关闭。

**示例运行效果：**

```
conn1 is conn2 ? True
建立数据库连接
执行SQL语句：select * from student
捕获到异常：division by zero
关闭数据库连接
无法执行SQL：数据库连接未打开
```
